# Monacopet Store

Site de um petshop voltado para cães e gatos, desenvolvido para a disciplina **Fundamentos de Sistemas Web** (PUCRS Online), **Fase 1**.

Autoria: Maryanne

## Descrição

A Monacopet Store apresenta seus produtos e serviços de forma organizada, para que o cliente conheça a loja, consulte descrições e valores e saiba quais serviços contam com tele-busca. Nesta fase, o site foi construído apenas com **HTML**, sem CSS, Bootstrap ou JavaScript.

## Funcionalidades

- **Página inicial (`index.html`)**: apresentação do petshop, tabela de seções com atalhos para produtos e serviços e os diferenciais da loja.
- **Produtos (`produtos.html`)**: 2 produtos de cada categoria (Ração, Brinquedos e Higiene), exibidos em tabelas com foto, descrição e valor, além de links de atalho para cada categoria.
- **Serviços (`servicos.html`)**: banho, tosa, consulta veterinária e vacinação, em tabela com foto, descrição, valor e informação de tele-busca (sim ou não).
- **Cabeçalho**: nome e informações do petshop (descrição, horário e cidade) e menu de navegação entre as páginas.
- **Rodapé**: nome da loja, contato, links de navegação, direitos autorais e autoria do site.

- HTML5 (estrutura, títulos, listas, tabelas, links, imagens e elementos semânticos como `header`, `nav`, `main`, `section` e `footer`)
- Git e GitHub para versionamento e hospedagem do código
- GitHub Pages para publicação do site

## Como visualizar

Acesse o site pelo link do GitHub Pages deste repositório.

Para ver localmente, baixe o repositório, mantenha a pasta `imagens` ao lado dos arquivos HTML e abra o `index.html` no navegador.

## Observações

- Nesta fase não há CSS, Bootstrap nem JavaScript. A estilização e a interatividade serão feitas na Fase 2.
- Os nomes, preços, e-mail e telefone são fictícios, criados para fins acadêmicos.
- As imagens são usadas apenas para ilustrar o trabalho acadêmico.
